Jiano — Native macOS AI Workstation

A premium macOS application built with SwiftUI + SwiftData. Connects 11+ AI providers — Anthropic Claude, OpenAI, Gemini, Grok, Ollama, AWS Bedrock, Azure and more — through a single glassmorphic interface.
